## Model-specific output style

When the active model is Opus 5 (`claude-opus-5`):

- Write in ASD-STE100 Simplified Technical English.
- Use short sentences. Maximum 20 words per sentence.
- Use one idea per sentence.
- Use active voice. Write "Claude reads the file." Not "The file is read by Claude."
- Use simple, common words. Write "use" not "utilize." Write "start" not "initiate."
- Use the same word for the same thing throughout. Do not use synonyms for technical terms.
- Give context before detail. State what the topic is before explaining it.
- When explaining a result, say what happened, then why it matters.
