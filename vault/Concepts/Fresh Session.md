# Fresh Session

Starting with no active conversation history, deliberately, because old assumptions would otherwise anchor the agent past the point they stopped being useful.

## When it's the right move

- The task direction changed, and old assumptions keep resurfacing.
- Reasoning is badly degraded (the [[Smart Zone vs Dumb Zone|dumb zone]]) rather than just verbose — compaction would just carry the confusion forward.
- Independent review is needed and must not be anchored by the implementation session's own discussion.
- Recovering from deep confusion where correcting each symptom in place costs more than restarting.

Not the right move merely to avoid resolving an unclear requirement — that just defers the same gap to the next session.

## How to start one well

Save decisions, failures, and next steps *before* clearing — reconstructing from memory after the fact loses exactly the details that mattered. Start the new session from durable artifacts and a concrete first action, not by pasting the old transcript. "Fresh" still loads repository instructions and durable decisions — it isn't a blank slate for the harness's standing rules, only for the conversation.
