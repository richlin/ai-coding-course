# Choosing Between Clear, Compact, Handoff, and Subagent — AI Coding Course

## Summary
Gives a decision framework for four context-management actions that each solve a different problem despite all reducing pressure on one context: clear/fresh (task changed or reasoning is badly degraded), compact (same healthy task, excess history), handoff (transfer across person/harness/repo/ownership), subagent (delegate a bounded task while the main session keeps coordination).

## Key takeaways
- Choosing the wrong action either preserves confusion (compacting broken reasoning) or loses task state (clearing when another owner needed a portable record).
- A subagent needs a defined input, output, scope, and verification before delegation — it isn't just extra context space for an unclear task.
- Save durable state before any of the four transitions, regardless of which one is chosen.
- Integration ownership stays with the parent task even when a subagent is delegated a bounded piece of work; validate the receiving context before allowing further edits.
