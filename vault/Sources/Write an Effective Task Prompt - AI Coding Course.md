# Write an Effective Task Prompt — AI Coding Course

## Summary
Introduces the assignment gap — the distance between the task an author holds in their head and the task actually written down — and gives a stable four-field prompt shape (desired outcome, context, constraints, done-when) to close it.

## Key takeaways
- Weak prompts are usually too compressed, not too short: "fix this" and "research context windows" both omit the details the author already knows and unconsciously assumes are shared.
- An agent fills an assignment gap with plausible guesses; fluent output is not evidence the guess was right.
- Minimum viable prompt: observed problem/outcome, context the agent can't discover, constraints, and observable evidence of success.
- Give a destination, not a turn-by-turn route — the test is "did I make success and the boundaries observable," not "did I specify every step."
