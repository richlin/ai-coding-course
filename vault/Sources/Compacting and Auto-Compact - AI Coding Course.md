# Compacting and Auto-Compact — AI Coding Course

## Summary
Defines compaction as summarizing an existing session to continue with less context, and auto-compact as the harness triggering that step at a pressure threshold. A compacted summary must preserve goals, constraints, decisions, evidence, current state, and next actions — poor summaries silently drop details later decisions depend on.

## Key takeaways
- Compaction extends a healthy session; it cannot repair confused reasoning already in that session.
- Save uncommitted state and artifacts before compacting — don't rely on the summary to capture them.
- Review the generated summary specifically for omitted non-goals and rejected proposals reappearing as if still active.
- Compact at a natural phase boundary; distinguish decisions actually made from alternatives merely explored.
- After auto-compact, restate the task and verification state before continuing — don't assume recall.
