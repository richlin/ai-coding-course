# Starting Context — AI Coding Course

## Summary
Defines starting context as what an agent needs before beginning a task — goal, constraints, repository instructions, current state, relevant files, known failures — sufficient for the first decision, not an attempt to explain the entire system up front.

## Key takeaways
- Good starting context is sufficient for the *first* decision; the agent searches outward as new questions arise, rather than being handed a repository dump.
- Include the exact acceptance criteria and the first verification command, plus the current repository/branch state.
- Label assumptions and known failures explicitly, and prefer links/paths over pasted content when tools can retrieve it.
- Don't present an outdated plan as current state, and don't ask the agent to "explore" without a concrete anchor or question.
