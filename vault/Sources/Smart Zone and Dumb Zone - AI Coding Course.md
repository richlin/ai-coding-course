# Smart Zone and Dumb Zone — AI Coding Course

## Summary
A reference-style companion to the fuller "Context Degradation" article, using the same terms: the smart zone is the part of a session where goals, evidence, and constraints stay clear; the dumb zone is a practical label for degraded behavior. The boundary is behavioral, not a fixed token threshold.

## Key takeaways
- Watch for repeated searches, stale plans, contradictory edits, and missed instructions as concrete degradation signals — not context percentage alone.
- Check whether a correction persists across the next two actions before trusting that the session has recovered.
- Choose compaction for a healthy task with excess history; choose a fresh session for confused reasoning — compacting unsupported assumptions just carries them forward.
- Treat "smart zone"/"dumb zone" as a practical heuristic describing session quality, not a property of the model itself — don't blame or argue with the agent when the real issue is context management.
