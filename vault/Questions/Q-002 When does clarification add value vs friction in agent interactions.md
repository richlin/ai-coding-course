# Q-002 — When does clarification add value vs. friction in agent interactions?

The "Clarify When Necessary" paper ([aclanthology.org/2025.findings-naacl.306/](https://aclanthology.org/2025.findings-naacl.306/)) shows that questions help when resolving uncertainty is worth the interaction cost, but unnecessary questions add friction.

**The open question:** What heuristics reliably distinguish "this question could change the result" from "the agent can safely infer this"? Is this task-type-dependent (reversible edit vs. architectural change), or is there a generalizable rule?
